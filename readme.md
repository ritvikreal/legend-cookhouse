# 🍽️ Legend Cookhouse Website

This is a responsive restaurant website created using HTML, CSS, and Bootstrap.  
The project represents a modern restaurant landing page design with attractive layout and user-friendly interface.

## 🚀 Features

- Responsive design
- Bootstrap layout
- Navigation bar
- Image carousel
- Menu section
- About section
- Contact section
- Footer section

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
